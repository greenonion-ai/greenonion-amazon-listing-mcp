# Security

Please report a suspected vulnerability privately to **security@greenonion.ai**. Do not include product photos, access tokens, passwords, or other customer data in a public GitHub issue.

Include the affected endpoint, a concise reproduction, and the potential impact. GreenOnion will acknowledge the report and coordinate next steps by email.

The hosted GreenOnion MCP servers use OAuth 2.1. Users should never place GreenOnion passwords or bearer tokens in repository files or MCP configuration files.
